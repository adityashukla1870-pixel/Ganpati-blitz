# Submission Drafts

## Short description

Ganpati Blitz is a festive multi-game arcade for Ganesh Chaturthi. Players can jump into six short skill games, chase personal bests, compete on campus-filtered leaderboards, challenge friends, and build progression through XP, achievements, Daily Challenge, and Blitz Mix.

## Detailed description

The arcade turns familiar festival motifs into distinct mechanics: collection, memory, rhythm, pattern recognition, maze navigation, and visual logic. Each game is designed for quick mobile-friendly sessions, with clear objectives, result screens, replay, and per-game ranking. Multiplayer rooms and Quick Match extend the same arcade identity into friendly competition.

## Gameplay instructions

Open Arcade, choose a game, read the short objective, and use touch or mouse controls. Finish the round before the timer or mistake limit, review the result, and replay to improve. Daily Challenge rewards are claimable only after the backend records a qualifying run.

## Multiplayer explanation

Players create or join a room with a short code, ready up, receive a synchronized countdown and match seed, then submit a bounded result to the shared match. Rating is separate from solo scores and XP.

## Accessibility explanation

Primary interactions support touch, keyboard-friendly navigation is used for standard controls, sound is optional, and result states include text rather than relying only on color.

## Demo walkthrough

1. Set up a display name and campus.
2. Open Arcade and show the six game cards.
3. Play a short Modak Rush round and show the result.
4. Open Profile to show XP, level, achievements, and best scores.
5. Open Daily Challenge and explain server-date validation.
6. Start Blitz Mix and complete several quick rounds.
7. Show a friend room and the multiplayer result flow.
